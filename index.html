Pedidos de orçamento

A importação de XML faz uma prévia, e a entrada só é gravada depois da sua confirmação. O sistema não consulta a SEFAZ em tempo real.

Importar notas fiscais

Notas de materiais entram no estoque; notas de serviço viram custo direto dos projetos. Confira os dados e só então confirme a entrada.

1. Selecionar as notas

MateriaisNotas de materiais (NF-e)

XML de NF-e ou PDF do DANFE. Os produtos entram no estoque.

ServiçosNotas de serviço (NFS-e)

XML de NFS-e (padrão nacional ou ABRASF das prefeituras) ou PDF. Não entra no estoque: o valor vira custo do projeto.

Nota de serviço Serviço Digitada

Retenções (opcionais):

Arraste os arquivos para a caixa certa ou clique em "Escolher arquivos". Na conferência, cada nota pode ter o tipo trocado. PDFs digitalizados passam por OCR em português; o XML continua sendo a fonte mais confiável.

2. Conferir antes de lançar

Selecione um ou mais arquivos para visualizar os dados.

Dados e segurança

Nuvem, cópia de segurança e restauração.

Onde ficam os dados

Na nuvem (Firebase), gravados automaticamente a cada alteração e compartilhados ao vivo com os usuários liberados.

Uma cópia fica neste navegador para o sistema abrir rápido e funcionar sem internet; o que for feito offline sobe sozinho no próximo login.

Nuvem + cópia local

Backup e restauração

Exporte periodicamente um arquivo JSON e guarde-o em local seguro. A restauração substitui a base atual.

Leitura de PDF / OCR

PDF.js extrai texto; Tesseract.js pode reconhecer páginas digitalizadas como imagem.

A aplicação tenta carregar as bibliotecas locais em ./libs/ e, se ausentes, recorre à CDN. OCR é mais lento e requer revisão humana.

Importação de backup

Conectado à nuvem, os registros do backup são enviados e juntados aos que já existem (nada é apagado). Faça um backup atual antes de continuar.

Zona de perigo — apagar a cópia deste navegador

Remove a cópia local dos dados e encerra a sessão. A base na nuvem não é apagada: ao entrar de novo, os dados voltam. Alterações ainda não enviadas (feitas offline) serão perdidas.
